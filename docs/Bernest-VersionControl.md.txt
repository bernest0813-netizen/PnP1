## Topic: Version Control & Git

Version control, also known as revision control, records changes to a file or set of files over time so that you can recall specific versions later. In this class, we are learning Git. Update the information below where indicated.

**1. There are three types of version control.**

[Long Version Control Systems- Uses a simple database on the local computer to track changes to files.
CVCS- Uses a single centralized server that contains all the versioned files, and several clients check out the files from that central place.
DVCS- Clients fully mirror the repo, if any server dies, any of the client repos can back up to the server to restore]
